# Bombsquad Special Abilities System
A special ability framework for [Bombsquad](https://github.com/efroemling/ballistica) game engine (API 9). Assigns a special ability to each available character in game.

## FEATURES
* **Character specific special ability:**
    * **Snake Shadow**: Flips
    * **Kronk**: Increase punch power
    * **B-9000**: Emp pulse
    * **Zoe**: Nuke
    * **Mel**: Infinite sticky bombs
    * **Pascal**: Ice skating
    * **Frosty**: Freeze punch
    * **Agent Johnson**: Invicinbility
    * **Grumbledorf**: Cursed domain
    * **Taobao Mascot**: Soldier
    * ***Remaining will be added in time. Abilities are also subject to change in time
* **Customize abilities to liking:**
    * In app settings system to change characters abilities, skill cooldown, skill range, e.t.c.
* **Added text to display and show percent of ability charge.**

## VERSION
* **1.0**

## INSTALLATION
1. Download special ability file.
2. Upload file to workspace or mods folder.
3. Enable plugin in-game.
4. Can also work on servers if placed in mods folder
5. Can also download from plugin manager(Will be uploaded when a stable version is available)
